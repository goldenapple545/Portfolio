# Egor Portfolio

Статический сайт-портфолио, подготовленный для публикации на GitHub Pages или Netlify.

## Структура

- `index.html` - главная страница сайта.
- `projects.html` - страница проектов, которая рендерит карточки из JSON.
- `editor.html` - локальный редактор проектов.
- `data/projects.json` - данные карточек проектов для опубликованного сайта.
- `assets/css/styles.css` - стили интерфейса.
- `assets/js/main.js` - небольшой клиентский JavaScript.
- `assets/js/editor.js` - логика редактора проектов.
- `assets/img/` - будущие изображения, обложки проектов и аватар.
- `egor_projects.html` - исходная верстка, оставлена как референс.
- `netlify.toml` - настройки деплоя на Netlify.
- `.github/workflows/pages.yml` - workflow для GitHub Pages.
- `start-server.sh` - bash-скрипт локального запуска.

## Локальный запуск

```bash
python -m http.server 4173
```

После запуска сайт будет доступен по адресу `http://localhost:4173`.

Если нужен запуск через npm:

```bash
npm run dev
```

Если нужен запуск через bash-скрипт:

```bash
bash ./start-server.sh
```

Скрипт открывает редактор в браузере автоматически. Окно терминала нужно оставить
открытым: пока оно работает, локальный сайт доступен по адресу
`http://localhost:4173/editor.html`.

## Редактор проектов

Редактор доступен по адресу `http://localhost:4173/editor.html`.

Возможности:

- создание, редактирование, дублирование и удаление проектов;
- загрузка обложки и картинок галереи с компьютера;
- сохранение черновиков в браузере;
- импорт и экспорт `projects.json`;
- предпросмотр карточек перед публикацией.

Для публикации изменений:

1. Открыть редактор и подготовить проекты.
2. Нажать `Экспорт JSON`.
3. Заменить файл `data/projects.json` экспортированным файлом.
4. Сделать commit и push в репозиторий.

## GitHub Pages

1. Залить проект в репозиторий GitHub.
2. В настройках репозитория открыть `Settings -> Pages`.
3. Выбрать источник `GitHub Actions`.
4. Убедиться, что основная ветка называется `main`.
5. Сделать push в `main`, workflow `.github/workflows/pages.yml` опубликует сайт.

## Netlify

1. Создать новый сайт из Git-репозитория.
2. Build command оставить пустым.
3. Publish directory указать `.`.
4. Netlify применит настройки из `netlify.toml`.
