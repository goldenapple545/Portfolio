# Egor Portfolio

Статический сайт-портфолио Егора Виктурова — VR-разработчика, геймдизайнера и музыканта. Публикуется на GitHub Pages.

## Разделы сайта

### Главная (`index.html`)

Лендинг с представлением автора: ключевые навыки, специализация (VR, Unity, XR Interaction Toolkit), кратко о себе и навигация по разделам.

### Проекты (`projects.html`)

Публичная страница с карточками проектов. Данные загружаются динамически из `data/projects.json`. Каждый проект включает обложку, галерею, описание, технологии, возможности и ссылки. Карточки автоматически чередуют ориентацию.

### Музыка (`music.html`)

Раздел с музыкальными работами: саундтреки для VR-игр, гитарные записи, плейлисты и видео.

### Контакты (`contacts.html`)

Страница с контактной информацией и формой обратной связи (через FormSubmit, без серверной части).

### Редактор (`editor.html`)

Локальный интерфейс для управления проектами. Открывается как файл (не через сервер). Позволяет добавлять, редактировать, удалять и менять порядок проектов. Результат сохраняется в `data/projects.json`.

## Структура

| Файл / Папка | Назначение |
|---|---|
| `index.html` | Главная страница |
| `projects.html` | Публичная страница проектов |
| `music.html` | Страница с музыкой |
| `contacts.html` | Контакты и форма обратной связи |
| `editor.html` | Локальный редактор проектов |
| `data/projects.json` | Единый источник данных о проектах |
| `assets/js/main.js` | Загрузка и рендер проектов на `projects.html` |
| `assets/js/editor.js` | Логика локального редактора |
| `assets/js/i18n.js` | Система локализации (RU / EN) |
| `assets/js/contacts.js` | Логика страницы контактов |
| `assets/css/styles.css` | Единый файл стилей |
| `assets/img/` | Изображения проекта |

## Локальный запуск

```bash
bash ./start-server.sh
# или
npm run dev
```
